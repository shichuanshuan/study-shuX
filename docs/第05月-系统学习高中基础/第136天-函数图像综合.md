## 学习计划

### 第 136 天：函数图像综合

知识点：定义域、值域、单调性、图像变换。

练习任务：完成具体题目 6 道；每题写出至少两个性质。

订正重点：先看定义域，再看单调和特殊点。

具体题目：

```text
1. 求 y=log_2(x+1) 的定义域和值域
2. 求 y=2^x+3 的值域
3. 判断 y=(1/3)^x-1 的单调性和值域
4. 求 y=sqrt(x-2) 的定义域和值域
5. 写出 y=(x-3)^2+2 的顶点和单调区间
6. 求 y=1/(x+1) 的定义域
```
