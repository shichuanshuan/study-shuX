## 学习计划

### 第 125 天：对数比较与对数不等式

知识点：对数函数单调性、比较大小、对数不等式。

练习任务：完成具体题目 6 道；先判断底数大于 1 还是小于 1。

订正重点：底数在 0 到 1 之间时，不等号方向反转。

具体题目：

```text
1. 比较 log_2 3 与 log_2 5
2. 比较 log_(1/2) 3 与 log_(1/2) 5
3. 解不等式 log_2 x > 3
4. 解不等式 log_3(x-1) <= 2
5. 解不等式 log_(1/2) x > 2
6. 解不等式 log_2(2x-1) >= 1
```

## 答案与解析

### 第 125 天：对数比较与对数不等式

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | log_2 3<log_2 5 | 底数大于 1，递增。 |
| 2 | log_(1/2) 3>log_(1/2) 5 | 底数小于 1，递减。 |
| 3 | x>8 | log_2 x>3 等价于 x>2^3。 |
| 4 | 1<x<=10 | 真数 x-1>0，且 x-1<=9。 |
| 5 | 0<x<1/4 | 底数小于 1，x<(1/2)^2。 |
| 6 | x>=3/2 | 2x-1>=2，且真数自动为正。 |
