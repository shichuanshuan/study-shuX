## 学习计划

### 第 132 天：图像综合

知识点：指数、对数、幂函数图像综合判断。

练习任务：完成具体题目 6 道；先判断定义域和值域。

订正重点：图像题先看定义域、单调性、特殊点。

具体题目：

```text
1. 写出 y=2^(x-1)+1 的单调性和值域
2. 写出 y=log_2(x+2) 的定义域和单调性
3. 写出 y=(x-1)^2-4 的顶点和单调区间
4. 判断 y=1/(x-2) 的定义域和值域
5. 求 y=sqrt(x-1)+2 的定义域和值域
6. 判断 y=log_(1/2)(x-1) 的单调性
```

## 答案与解析

### 第 132 天：图像综合

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 单调递增，值域 (1,+∞) | 2^(x-1)>0 后上移 1。 |
| 2 | 定义域 (-2,+∞)，单调递增 | 真数 x+2>0，底数 2>1。 |
| 3 | 顶点 (1,-4)；递减 (-∞,1]，递增 [1,+∞) | 二次函数顶点式。 |
| 4 | 定义域 x≠2，值域 y≠0 | 倒数型函数。 |
| 5 | 定义域 [1,+∞)，值域 [2,+∞) | 根号整体右移 1、上移 2。 |
| 6 | 单调递减 | 底数 1/2 在 0 到 1 之间，定义域 x>1。 |
