## 学习计划

### 第 123 天：对数函数图像

知识点：`y = log_a x`、定义域、值域、单调性。

练习任务：完成具体题目 6 道；先判断底数范围。

订正重点：对数函数定义域是 `(0,+∞)`，图像过 `(1,0)`。

具体题目：

```text
1. 写出 y=log_2 x 的定义域和值域
2. 写出 y=log_(1/2) x 的定义域和值域
3. 判断 y=log_3 x 的单调性
4. 判断 y=log_(1/3) x 的单调性
5. 求 y=log_2(x-1) 的定义域
6. 求 y=log_2 x + 1 经过的特殊点
```

```text

3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

## 答案与解析

### 第 123 天：对数函数图像

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 定义域 (0,+∞)，值域 R | 真数必须为正。 |
| 2 | 定义域 (0,+∞)，值域 R | 底数小于 1 只影响单调性。 |
| 3 | 单调递增 | 底数 3>1。 |
| 4 | 单调递减 | 底数 1/3 在 0 到 1 之间。 |
| 5 | (1,+∞) | x-1>0。 |
| 6 | (1,1) | y=log_2 x 过 (1,0)，上移 1。 |
