### 第 118 天：指数比较与指数不等式

知识点：指数函数单调性、比较大小、基础指数不等式。

练习任务：完成具体题目 6 道；先判断底数范围。

订正重点：底数在 0 到 1 之间时，不等号方向会反。

具体题目：

```text
1. 比较 2^3 与 2^5
2. 比较 (1/3)^2 与 (1/3)^4
3. 解不等式 2^x > 16
4. 解不等式 3^(x-1) <= 9
5. 解不等式 (1/2)^x > 1/8
6. 解不等式 (1/3)^(x+1) <= 1/9
```

## 答案与解析

### 第 118 天：指数比较与指数不等式

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 2^3<2^5 | 底数大于 1。 |
| 2 | (1/3)^2>(1/3)^4 | 底数小于 1，指数越大值越小。 |
| 3 | x>4 | 16=2^4。 |
| 4 | x<=3 | 9=3^2，x-1<=2。 |
| 5 | x<3 | 1/8=(1/2)^3，底数小于 1 不等号反向。 |
| 6 | x+1>=2，即 x>=1 | (1/3)^(x+1) <= (1/3)^2，反向比较指数。 |
