## 学习计划

### 第 131 天：图像对称与翻折

知识点：关于坐标轴对称、关于原点对称、绝对值翻折。

练习任务：完成具体题目 6 道；画草图辅助。

订正重点：`|f(x)|` 把 x 轴下方翻到上方。

具体题目：

```text
1. y=f(-x) 与 y=f(x) 的图像有什么关系
2. y=-f(x) 与 y=f(x) 的图像有什么关系
3. y=|x| 由 y=x 怎样翻折得到
4. y=|x^2-1| 与 y=x^2-1 相比，下方部分怎样变化
5. 写出 y=x^2 关于 x 轴对称后的解析式
6. 写出 y=2^x 关于 y 轴对称后的解析式
```

## 答案与解析

### 第 131 天：图像对称与翻折

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 关于 y 轴对称 | x 换成 -x。 |
| 2 | 关于 x 轴对称 | 函数值取相反数。 |
| 3 | 把 y=x 在 x 轴下方部分翻折到上方 | 即 y=|x|。 |
| 4 | x 轴下方部分翻折到 x 轴上方，上方不变 | 绝对值作用在函数值。 |
| 5 | y=-x^2 | 关于 x 轴：y 变 -y。 |
| 6 | y=2^(-x)，即 (1/2)^x | 关于 y 轴：x 变 -x。 |
