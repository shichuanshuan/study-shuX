```text

本阶段使用说明：文中的“冲刺卷 1/2/3/4”指你手边的高质量模拟卷或最近一轮真题回炉卷；如果卷型不同，就按“选择填空、前 3 道解答题、导数、解析几何、压轴题”的功能位置替换。每天仍然使用 A/B/C/D 分类：A 类会做且做对；B 类会做但算错或不规范；C 类看答案能懂但独立做不出；D 类完全不会或暂时超出能力。

5. 若 k1k2=-1 恒成立，说明几何意义
6. 把一道定值错题中的含参表达式化到最简
7. 重做最近 2 道定点定值错题，只写消参或化简步骤
8. 整理定点定值题的 3 个识别信号
```

巩固加练：

```text
1. 按当天题型再补做同类题 10-15 道
2. 至少包含 5 道基础变式、5 道中档变式、2 道限时题

```

```text

```
