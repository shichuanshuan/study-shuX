# 第 4 月系统学习高中基础每日计划

> 主题：集合、逻辑与函数基础。目标是把高中函数学习的入口打稳：会用集合语言，会判断充分必要条件，会求定义域、解析式、值域、单调性、奇偶性，并能读懂基础函数图像。

---

## 一、本月目标

```text
1. 熟悉集合、命题、充分必要条件的基本语言
2. 会求常见函数定义域和简单解析式
3. 会求基础函数值域，能判断单调性和奇偶性
4. 能读懂函数图像、零点和简单图像变换
```

每天训练分三层：基础必做完成本小节“具体题目”；巩固加练继续补同类题；错题加练围绕当天错题对应知识点追加练习。题目做完后立刻订正，错题按 B/C/D 分类。
