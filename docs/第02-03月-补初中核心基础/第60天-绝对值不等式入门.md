## 学习计划

### 第 60 天：绝对值不等式入门

知识点：

```text
绝对值意义
|x| < a
|x| > a
|x - m| 与距离
```

练习任务：

```text
完成下方具体题目 10 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
小于型是否写成中间区间
大于型是否写成两边区间
是否理解绝对值表示距离
```

具体题目：

```text
1. |x| = 5
2. |x| < 3
3. |x| > 2
4. |x - 1| = 4
5. |x + 2| <= 3
6. |x - 3| < 2
7. |x + 1| > 4
8. |2x| <= 6
9. |x/2| > 3
10. |x - 5| >= 1
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 60 天：绝对值不等式入门

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | x=±5 | 绝对值等于正数有两个解。 |
| 2 | -3<x<3 | \|x\|<a 表示 -a<x<a。 |
| 3 | x<-2 或 x>2 | \|x\|>a 在两侧。 |
| 4 | x=5 或 x=-3 | x-1=±4。 |
| 5 | -5<=x<=1 | -3<=x+2<=3。 |
| 6 | 1<x<5 | -2<x-3<2。 |
| 7 | x<-5 或 x>3 | x+1<-4 或 x+1>4。 |
| 8 | -3<=x<=3 | \|2x\|<=6 等价于 \|x\|<=3。 |
| 9 | x<-6 或 x>6 | \|x/2\|>3 等价于 \|x\|>6。 |
| 10 | x<=4 或 x>=6 | x-5<=-1 或 x-5>=1。 |
