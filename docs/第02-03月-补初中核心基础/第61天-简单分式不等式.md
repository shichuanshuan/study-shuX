## 答案与解析

### 第 61 天：简单分式不等式

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | x>0 | 分子为正，分式为正需分母为正。 |
| 2 | x<0 | 分子为正，分式为负需分母为负。 |
| 3 | x<-1 或 x>2 | 临界点 -1、2，同号为正，x=-1 不取。 |
| 4 | -3<x<4 | 临界点 -3、4，异号为负。 |
| 5 | x<=0 或 x>2 | 临界点 0、2；x=0 使分式为 0 可取，x=2 分母为 0 不取。 |
| 6 | -2<x<=1 | 临界点 -2、1，异号或零，-2 不取。 |
| 7 | x≠5 | 分母 x-5 不能为 0。 |
| 8 | x>-1 | 2 为正，分式为正需 x+1>0。 |
