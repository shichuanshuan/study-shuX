```text
1. x 取什么值时，1/(x - 3) 有意义
2. x 取什么值时，2/(x + 5) 有意义
3. x 取什么值时，(x + 1)/(x^2 - 4) 有意义
4. 约分：6x/9
5. 约分：4a^2/8a
6. 约分：(x^2 - 9)/(x + 3)
7. 约分：(a^2 - 4a)/(a)
8. 约分：(x^2 + 5x + 6)/(x + 2)
9. 化简：(m^2 - 16)/(m - 4)
10. 判断并化为最简分式：(2x^2 + 6x)/(4x)
```

## 答案与解析

### 第 43 天：分式意义和约分

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | x≠3 | 分母 x-3 不能为 0。 |
| 2 | x≠-5 | 分母 x+5 不能为 0。 |
| 3 | x≠2 且 x≠-2 | x^2-4=(x-2)(x+2)，分母不能为 0。 |
| 4 | 2x/3 | 6x/9 同除以 3。 |
| 5 | a/2（a≠0） | 4a^2/8a 约去 4a，原分母要求 a≠0。 |
| 6 | x-3（x≠-3） | x^2-9=(x-3)(x+3)，约去 x+3。 |
| 7 | a-4（a≠0） | a^2-4a=a(a-4)，约去 a。 |
| 8 | x+3（x≠-2） | 分子为 (x+2)(x+3)。 |
| 9 | m+4（m≠4） | m^2-16=(m-4)(m+4)。 |
| 10 | (x+3)/2（x≠0） | 2x^2+6x=2x(x+3)，4x=4x。 |
