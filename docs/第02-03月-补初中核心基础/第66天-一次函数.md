## 学习计划

### 第 66 天：一次函数

知识点：

```text
y = kx + b
k 的意义
b 的意义
与坐标轴交点
增减性
```

练习任务：

```text
完成下方具体题目 10 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
k 的正负和增减性是否对应
求 x 轴交点时是否令 y = 0
求 y 轴交点时是否令 x = 0
```

具体题目：

```text
1. y = 2x + 1，求 x = 0 时的 y
2. y = 2x + 1，求 x = 3 时的 y
3. y = -x + 4，求与 y 轴交点
4. y = -x + 4，求与 x 轴交点
5. y = 3x - 6 的斜率 k 是多少
6. y = -2x + 5 是递增还是递减
7. 过点 (0, 2) 且斜率为 3 的一次函数解析式是什么
8. 一次函数 y = kx + 1 经过点 (2, 5)，求 k
9. 一次函数 y = 2x + b 经过点 (1, 7)，求 b
10. 直线 y = -3x + 6 与 x 轴交点是什么
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
