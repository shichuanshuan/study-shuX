## 学习计划

### 第 45 天：分式加减

知识点：

```text
同分母加减
异分母通分
最简公分母
分式化简
```

练习任务：

```text
完成下方具体题目 10 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
最简公分母是否找对
通分后分子是否整体加减
结果是否继续约分
```

具体题目：

```text
1. 1/x + 2/x
2. 5/a - 3/a
3. 1/x + 1/(2x)
4. 2/(x + 1) - 1/(x + 1)
5. 1/(3x) + 1/(6x)
6. 1/(x - 2) + 3/(x - 2)
7. 1/x + 1/(x + 1)
8. 2/(x - 1) - 1/(x + 1)
9. x/(x - 3) - 3/(x - 3)
10. 1/(a + 2) + 1/(a - 2)
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 45 天：分式加减

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 3/x | 同分母分子相加。 |
| 2 | 2/a | 同分母分子相减。 |
| 3 | 3/(2x) | 通分到 2x。 |
| 4 | 1/(x+1) | 同分母相减。 |
| 5 | 1/(2x) | 通分到 6x：2/6x+1/6x=3/6x。 |
| 6 | 4/(x-2) | 同分母相加。 |
| 7 | (2x+1)/(x(x+1)) | 通分到 x(x+1)。 |
| 8 | (x+3)/((x-1)(x+1)) | 分子 2(x+1)-(x-1)=x+3。 |
| 9 | 1 | (x-3)/(x-3)=1，注意 x≠3。 |
| 10 | 2a/(a^2-4) | 通分为 (a-2+a+2)/((a+2)(a-2))。 |
