订正重点：

```text
零点是否等同于令 y = 0
判别式和交点个数是否对应
看图像时是否分清大于 0 和小于 0
```

具体题目：

```text
1. y = x^2 - 4 的零点
2. y = x^2 + 1 是否有零点
3. y = x^2 - 4x + 3 与 x 轴交点
4. y = x^2 + 2x + 1 与 x 轴交点
5. y = x^2 - 6x + 8 的零点
6. y = -x^2 + 4 的零点
7. 判断 y = x^2 - 2x + 5 与 x 轴交点个数
8. 判断 y = x^2 - 4x + 4 与 x 轴交点个数
9. 根据二次函数图像 y = (x - 1)(x - 3)，写出 y > 0 的 x 范围
10. 根据二次函数图像 y = (x + 2)(x - 4)，写出 y < 0 的 x 范围
```
