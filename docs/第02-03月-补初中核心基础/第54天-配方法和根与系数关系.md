订正重点：

```text
配方时两边是否同时加同一个数
x1 + x2 = -b/a 是否记反
x1x2 = c/a 是否漏掉 a
```

具体题目：

```text
1. 用配方法解：x^2 + 6x + 5 = 0
2. 用配方法解：x^2 - 4x + 1 = 0
3. 方程 x^2 - 5x + 6 = 0 的两根和与积分别是多少
4. 方程 2x^2 - 7x + 3 = 0 的两根和与积分别是多少
5. 若 x^2 + kx + 4 = 0 的两根和为 -5，求 k
6. 若 x^2 - 3x + m = 0 的两根积为 2，求 m
7. 已知一元二次方程两根为 2 和 3，写出一个首项系数为 1 的方程
8. 方程 3x^2 - 6x + 1 = 0 的两根和是多少
```

## 答案与解析

### 第 54 天：配方法和根与系数关系

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | x=-1 或 -5 | (x+3)^2=4，故 x+3=±2。 |
| 2 | x=2±sqrt(3) | (x-2)^2=3。 |
| 3 | 和 5，积 6 | x^2-5x+6 中两根和为 5、积为 6。 |
| 4 | 和 7/2，积 3/2 | 两根和 -b/a=7/2，积 c/a=3/2。 |
| 5 | k=5 | 两根和为 -k=-5。 |
| 6 | m=2 | 首项系数为 1 时两根积等于常数项。 |
| 7 | x^2-5x+6=0 | 两根和 5，积 6。 |
| 8 | 2 | 两根和 -b/a=6/3=2。 |
