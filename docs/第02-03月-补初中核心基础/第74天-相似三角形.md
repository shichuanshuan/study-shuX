知识点：

```text
相似判定

周长比
面积比

```

练习任务：

```text
完成下方具体题目 8 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
相似比和面积比是否平方关系
对应边是否找错
比例式是否写反
```

具体题目：

```text
1. 两个三角形对应角分别相等，是否相似
2. 两个三角形对应边成比例，是否相似
3. 两个相似三角形相似比为 2:3，周长比是多少
4. 两个相似三角形相似比为 2:3，面积比是多少
5. 两个相似三角形周长比为 4:5，相似比是多少
6. 两个相似三角形面积比为 9:16，相似比是多少
7. 相似三角形一组对应边为 6 和 9，另一边为 8，对应边是多少
8. 若 triangle ABC 与 triangle DEF 相似，AB 对应 DE，BC 对应 EF，写出一个比例式
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 74 天：相似三角形

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 是 | AAA 可判定三角形相似。 |
| 2 | 是 | SSS 相似判定。 |
| 3 | 2:3 | 周长比等于相似比。 |
| 4 | 4:9 | 面积比等于相似比的平方。 |
| 5 | 4:5 | 周长比等于相似比。 |
| 6 | 3:4 | 面积比开方得到相似比。 |
| 7 | 12 | 若 6 对应 9，相似比为 2:3，8 的对应边为 8×3/2。 |
| 8 | AB/DE=BC/EF | 也可写 AB:DE=BC:EF。 |
