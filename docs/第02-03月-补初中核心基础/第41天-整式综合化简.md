## 学习计划

### 第 41 天：整式综合化简

知识点：

```text
先展开
再合并同类项
能分解时再分解
化简求值
```

练习任务：

```text
完成下方具体题目 10 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
步骤是否完整
代入求值前是否先化简
结果是否能继续合并或分解
```

具体题目：

```text
1. x(x + 2) - (x + 1)^2
2. 2x(x - 3) - x(x + 1)
3. (x + 4)(x - 1) - x^2
4. (2a - 3)^2 - 4a(a - 1)
5. (m + 2)(m - 5) - (m - 1)^2
6. 化简求值：2x^2 - 3x + x^2 + 5x，其中 x = -2
7. 化简求值：(a + 3)^2 - a(a + 6)，其中 a = 4
8. 先化简再求值：3x(x - 2) - (x - 1)(3x + 2)，其中 x = 5
9. 化简：(x + 2)(x + 5) - (x + 3)^2
10. 化简：(2a + b)(2a - b) - 3a(a - b)
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
