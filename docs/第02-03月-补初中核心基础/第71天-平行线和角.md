订正重点：

```text
同位角、内错角、同旁内角是否能在图上找到
是用性质还是用判定是否分清
角度计算是否漏条件
```

具体题目：

```text
1. 两条平行线被一条直线所截，同位角是否相等
2. 两条平行线被一条直线所截，内错角是否相等
3. 两条平行线被一条直线所截，同旁内角和是多少
4. 若两条直线被第三条直线所截，同位角相等，能否判断两直线平行
5. 若两条直线被第三条直线所截，内错角相等，能否判断两直线平行
6. 一个角为 55°，它的补角是多少
7. 一个角为 35°，它的余角是多少
8. 两条平行线中一组同旁内角一个为 120°，另一个是多少
```
