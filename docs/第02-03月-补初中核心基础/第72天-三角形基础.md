## 学习计划

### 第 72 天：三角形基础

知识点：

```text
三角形内角和
外角性质
等腰三角形
等边三角形
三边关系
```

练习任务：

```text
完成下方具体题目 8 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
等腰三角形是否考虑腰和底的不同情况
外角等于两个不相邻内角之和是否会用
三边关系是否两边之和大于第三边
```

具体题目：

```text
1. 三角形两角为 30°、80°，第三角是多少
2. 等腰三角形顶角为 50°，底角是多少
3. 等腰三角形一个底角为 65°，顶角是多少
4. 正三角形每个内角是多少
5. 三角形一个外角为 120°，一个不相邻内角为 45°，另一个不相邻内角是多少
6. 三边 3、4、8 能否构成三角形
7. 三边 5、6、10 能否构成三角形
8. 三角形两边为 4 和 7，第三边 x 的范围是什么
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 72 天：三角形基础

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 70° | 三角形内角和 180°。 |
| 2 | 65° | 两个底角相等，各为 (180-50)/2。 |
| 3 | 50° | 顶角=180-2×65。 |
| 4 | 60° | 正三角形三个角相等。 |
| 5 | 75° | 外角等于两个不相邻内角和。 |
| 6 | 不能 | 3+4<8，不满足两边之和大于第三边。 |
| 7 | 能 | 5+6>10 且任意两边差小于第三边。 |
| 8 | 3<x<11 | 第三边大于两边差、小于两边和。 |
