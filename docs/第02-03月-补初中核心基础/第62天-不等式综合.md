## 学习计划

### 第 62 天：不等式综合

知识点：

```text
一元一次不等式
不等式组
绝对值不等式
分式不等式入门
```

练习任务：

```text
完成下方具体题目 8 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
不同题型的第一步是否分清
解集是否有交并意识
端点能不能取是否判断清楚
```

具体题目：

```text
1. 解不等式：-3x + 2 > 11
2. 解不等式组：x > -2，x <= 4
3. |x - 3| = 2
4. |x + 1| < 4
5. 解不等式：2(x + 1) <= 3x - 4
6. 解不等式组：2x - 1 >= 5，x + 2 < 8
7. 解不等式：(x - 3)/(x + 2) > 0
8. 解不等式：5 - 2x < 1
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

| 1 | x<-3 | -3x>9，除以 -3 反向。 |
