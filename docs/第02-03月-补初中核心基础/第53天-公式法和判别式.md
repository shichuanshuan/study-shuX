
必须背熟：

```text
ax^2 + bx + c = 0
Δ = b^2 - 4ac
x = (-b ± sqrt(Δ)) / (2a)
```

具体题目：

```text
1. 用公式法解：x^2 + 4x + 1 = 0
2. 用公式法解：2x^2 - 3x - 2 = 0
3. 用公式法解：x^2 - x - 1 = 0
4. 判断 x^2 - 6x + 9 = 0 的根的情况
5. 判断 x^2 + x + 1 = 0 的根的情况
6. 判断 2x^2 - 4x + 2 = 0 的根的情况
7. 判断 x^2 - 5x + 6 = 0 的根的情况
8. 方程 x^2 + 2x + k = 0 有两个相等实根，求 k
```
