订正重点：

```text

系数相加减，字母部分不变
不要把不同字母项合并
```

## 答案与解析

### 第 33 天：整式加减和合并同类项

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 6x | 同类项系数相加：3+5-2=6。 |
| 2 | 6a+4b | a 项和 b 项分别合并。 |
| 3 | 8m^2+6m | 平方项、一次项不能合并。 |
| 4 | 5x+2y | 7x-2x=5x，-3y+5y=2y。 |
| 5 | a^2b+3ab^2 | a^2b 与 ab^2 不是同类项。 |
| 6 | 10p-q | 6p+4p=10p，-2q+q=-q。 |
| 7 | 5x^2+4x | 同类项按次数分别合并。 |
| 8 | 7a | 括号内 3a-2a=a，8a-a=7a。 |
| 9 | 2x+9y | 5x-3x=2x，2y+7y=9y。 |
| 10 | 10m^2n-mn^2 | 只有 m^2n 项能合并。 |
