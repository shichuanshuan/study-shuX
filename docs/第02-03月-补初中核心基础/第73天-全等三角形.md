## 学习计划

### 第 73 天：全等三角形

知识点：

```text
SSS
SAS
ASA
AAS
HL
全等后的对应边角
```

练习任务：

```text
完成下方具体题目 8 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
条件是否足够
对应关系是否找对
证明步骤是否有依据
```

具体题目：

```text
1. 三边分别相等的两个三角形是否全等
2. 两边及夹角分别相等的两个三角形是否全等
3. 两角及夹边分别相等的两个三角形是否全等
4. 两角及其中一角的对边分别相等的两个三角形是否全等
5. 两个直角三角形斜边和一条直角边分别相等，是否全等
6. 全等三角形的对应边是否相等
7. 全等三角形的对应角是否相等
8. 已知 AB = DE，BC = EF，AC = DF，能否判断 triangle ABC 与 triangle DEF 全等
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
