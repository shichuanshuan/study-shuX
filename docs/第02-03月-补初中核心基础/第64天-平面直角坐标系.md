## 学习计划

### 第 64 天：平面直角坐标系

知识点：

```text
坐标点
象限
坐标轴
对称点
距离初步
```

练习任务：

```text
完成下方具体题目 10 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
横坐标和纵坐标是否写反
坐标轴上的点属于哪类情况
关于 x 轴或 y 轴对称时谁变号
```

具体题目：

```text
1. 点 A(3, -2) 在第几象限
2. 点 B(-4, 5) 在第几象限
3. 点 C(0, 3) 在哪条轴上
4. 点 D(-2, 0) 在哪条轴上
5. 点 P(2, 5) 关于 x 轴的对称点是什么
6. 点 Q(-3, 4) 关于 y 轴的对称点是什么
7. 点 M(1, -6) 关于原点的对称点是什么
8. 点 (3, 4) 到 x 轴的距离是多少
9. 点 (-5, 2) 到 y 轴的距离是多少
10. 点 A(1, 2)、B(1, 7) 的距离是多少
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 64 天：平面直角坐标系

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 第四象限 | x 正、y 负。 |
| 2 | 第二象限 | x 负、y 正。 |
| 3 | y 轴 | x=0 的点在 y 轴上。 |
| 4 | x 轴 | y=0 的点在 x 轴上。 |
| 5 | (2, -5) | 关于 x 轴对称，x 不变、y 变号。 |
| 6 | (3, 4) | 关于 y 轴对称，x 变号、y 不变。 |
| 7 | (-1, 6) | 关于原点对称，两个坐标都变号。 |
| 8 | 4 | 到 x 轴距离为 \|y\|。 |
| 9 | 5 | 到 y 轴距离为 \|x\|。 |
| 10 | 5 | 横坐标相同，距离为 \|7-2\|。 |
