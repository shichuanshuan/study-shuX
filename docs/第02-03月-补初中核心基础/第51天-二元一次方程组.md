## 学习计划

### 第 51 天：二元一次方程组

知识点：

```text
代入消元
加减消元
方程组检验
```

练习任务：

```text
完成下方具体题目 8 道
做完后立即订正，不边看答案边做
错题按 B/C/D 分类
从错题中挑 2-3 道写入错题本
```

订正重点：

```text
选择消元方法是否合理
加减时符号是否错
求出一个未知数后是否回代
```

具体题目：

```text
1. 用代入消元解：x + y = 9，x - y = 3
2. 用代入消元解：x + y = 10，2x + y = 16
3. 用代入消元解：2x + y = 7，x - y = 2
4. 用代入消元解：3x + 2y = 12，x + y = 5
5. 用加减消元解：x - 2y = 1，2x + y = 8
6. 用加减消元解：4x + y = 11，x + y = 5
7. 用加减消元解：2x - y = 3，x + 2y = 9
8. 用加减消元解：3x - y = 4，x + y = 8
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
