## 学习计划

### 第 153 天：基础恒等变换

知识点：同角关系、诱导公式、化简求值。

练习任务：完成具体题目 6 道；先观察能否用 `sin^2+cos^2=1`。

订正重点：恒等变换要写清每一步依据。

具体题目：

```text
1. 化简 1 - cos^2 x
2. 化简 sin^2 x/(1 - cos^2 x)
3. 化简 tan x · cos x / sin x
4. 化简 sin(π - x) - sin x
5. 化简 cos(π + x) + cos x
6. 已知 sin x = 3/5 且 x 在第二象限，求 cos x 和 tan x
```

## 答案与解析

### 第 153 天：基础恒等变换

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | sin^2 x | 用 sin^2 x+cos^2 x=1。 |
| 2 | 1 | 分母 1-cos^2 x=sin^2 x，需分母不为 0。 |
| 3 | 1 | tan x=sin x/cos x，约分后为 1。 |
| 4 | 0 | sin(π-x)=sinx。 |
| 5 | 0 | cos(π+x)=-cosx。 |
| 6 | cos x=-4/5，tan x=-3/4 | 第二象限 cos 负，tan 负。 |
