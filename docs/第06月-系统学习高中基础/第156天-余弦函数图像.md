### 第 156 天：余弦函数图像

知识点：`y = cos x` 的图像、定义域、值域、周期。

练习任务：完成具体题目 6 道；标出五点作图关键点。

订正重点：余弦函数是偶函数，周期为 `2π`。

具体题目：

```text
1. 写出 y=cos x 的定义域和值域
2. 写出 y=cos x 的最小正周期
3. 求 cos 0、cos(π/2)、cos π、cos(3π/2)、cos(2π)
4. 判断 y=cos x 是否为偶函数
5. 写出 y=cos x 在 [0,2π] 上的最大值
6. 写出 y=cos x 在 [0,2π] 上的零点
```
