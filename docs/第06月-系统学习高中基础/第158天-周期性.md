## 学习计划

### 第 158 天：周期性

知识点：周期函数、最小正周期、三角函数周期。

练习任务：完成具体题目 6 道；写出周期公式。

订正重点：`sin(ωx)` 和 `cos(ωx)` 的周期是 `2π/|ω|`。

具体题目：

```text
1. 求 y=sin(2x) 的周期
2. 求 y=cos(3x) 的周期
3. 求 y=tan(2x) 的周期
4. 求 y=sin(x/2) 的周期
5. 求 y=cos(2x+π/3) 的周期
6. 求 y=3sin(4x)-1 的周期
```
