## 学习计划

### 第 165 天：解三角形基础

知识点：已知两角一边、两边夹角、三边解三角形。

练习任务：完成具体题目 6 道；每题先判断用正弦还是余弦定理。

订正重点：先求第三角或夹角，再选公式。

具体题目：

```text
1. 已知 A=50°，B=60°，求 C
2. 已知 A=30°，B=45°，a=6，写出求 b 的式子
3. 已知 b=4，c=5，A=60°，求 a^2
4. 已知 a=5，b=6，c=7，写出求 cos A 的式子
5. 已知 a=8，A=45°，B=75°，求 C
6. 已知两边和夹角，应该优先使用哪个定理
```
