知识点：`sin^2 x + cos^2 x = 1`，`tan x = sin x / cos x`。

1. 已知 sin x = 3/5，且 x 在第一象限，求 cos x

4. 已知 tan x = 3/4，且 x 在第一象限，求 sin x 和 cos x
5. 化简 sin^2 x + cos^2 x + 1
