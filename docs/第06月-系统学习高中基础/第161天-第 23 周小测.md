## 学习计划

### 第 161 天：第 23 周小测

小测要求：限时完成具体题目 10 道；错题按图像、周期、变换、最值分类。

具体题目：

```text
1. 写出 y=sin x 的值域
2. 判断 y=cos x 的奇偶性
3. 写出 y=tan x 的周期
4. 求 y=sin(3x) 的周期
5. 求 y=cos(x/2) 的周期
6. 写出 y=2sin x 的振幅
7. y=sin(x+π/4) 由 y=sin x 怎样平移得到
8. 求 y=4cos x+1 的最大值
9. 写出 y=sin x 在 [0,2π] 上的零点
10. 判断 y=tan x 在 (-π/2,π/2) 上的单调性
```

巩固加练：

```text
1. 订正后按错题模块补做同类题 10-15 道
2. 正确率低于 80% 的模块，下周每天先回炉 10-15 分钟
3. 如果整次小测低于 70%，先回炉 2-3 天再进入下一周
```

错题加练：

```text
把 B/C/D 类错题各选 2 道，分别补 3 道同类题；D 类题必须回到对应知识点重新学一遍。
```
