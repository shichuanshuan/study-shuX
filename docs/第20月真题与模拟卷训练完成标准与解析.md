## 使用方法

```text
1. 本阶段很多“具体题目”其实是做卷、订正、统计和回炉动作
2. 因为真题卷/模拟卷由你手边资料决定，所以这里给完成标准和解析要点
3. 真正的数学题答案请以对应真题或模拟卷答案为准
4. 每次订正仍按 A/B/C/D 分类：A 会做且做对；B 会做但错；C 看答案能懂；D 完全不会
```
