## 学习计划

### 第 86 天：集合运算

知识点：交集、并集、补集、全集。

练习任务：完成具体题目 6 道；每题画一条数轴或简单示意图。

订正重点：交集取共同部分，并集取全部部分，补集先看全集。

具体题目：

```text
1. A = {1,2,3,4}，B = {3,4,5}，求 A ∩ B
2. A = {1,2,3,4}，B = {3,4,5}，求 A ∪ B
3. U = {1,2,3,4,5,6}，A = {2,4,6}，求 A 在 U 中的补集
4. A = {x | -1 <= x <= 3}，B = {x | x > 1}，求 A ∩ B
5. A = {x | x < 2}，B = {x | x >= -1}，求 A ∪ B
6. 若 A ∩ B = A，判断 A 与 B 的包含关系
```

## 答案与解析

### 第 86 天：集合运算

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | {3,4} | 交集取共同元素。 |
| 2 | {1,2,3,4,5} | 并集元素不重复。 |
| 3 | {1,3,5} | 补集必须相对全集 U。 |
| 4 | (1,3] | 同时满足 -1<=x<=3 且 x>1。 |
| 5 | R | x<2 与 x>=-1 合起来覆盖全体实数。 |
| 6 | A⊆B | A∩B=A 表示 A 的元素都在 B 中。 |
