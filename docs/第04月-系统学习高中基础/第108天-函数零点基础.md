## 学习计划

### 第 108 天：函数零点基础

知识点：零点、方程根、图像与 x 轴交点。

练习任务：完成具体题目 6 道；每题写出对应方程。

订正重点：零点是使 `f(x)=0` 的 x 值。

具体题目：

```text
1. 求 f(x)=2x-6 的零点
2. 求 f(x)=x^2-4 的零点
3. 求 f(x)=x^2-5x+6 的零点
4. 判断 f(x)=x^2+1 是否有零点
5. 求 y=(x-1)(x+3) 与 x 轴交点
6. 若 f(x)=x^2+2x+a 有两个相等零点，求 a
```

## 答案与解析

### 第 108 天：函数零点基础

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | x=3 | 令 2x-6=0。 |
| 2 | x=-2,2 | x^2=4。 |
| 3 | x=2,3 | 分解为 (x-2)(x-3)。 |
| 4 | 没有实零点 | x^2+1>0。 |
| 5 | (-3,0),(1,0) | 与 x 轴交点令 y=0。 |
| 6 | a=1 | 判别式 4-4a=0。 |
