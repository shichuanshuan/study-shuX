## 学习计划

### 第 90 天：充分条件与必要条件

知识点：充分条件、必要条件、充要条件。

练习任务：完成具体题目 6 道；每题写出 `p => q` 和 `q => p` 是否成立。

订正重点：先判断方向，再下结论。

具体题目：

```text
1. p: x > 3，q: x > 1，判断 p 是 q 的什么条件
2. p: x = 2，q: x^2 = 4，判断 p 是 q 的什么条件
3. p: 四边形是正方形，q: 四边形是矩形，判断 p 是 q 的什么条件
4. p: x 是偶数，q: x 能被 2 整除，判断 p 与 q 的关系
5. p: a = b，q: a^2 = b^2，判断 p 是 q 的什么条件
6. p: triangle ABC 是等边三角形，q: triangle ABC 是等腰三角形，判断 p 是 q 的什么条件
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 90 天：充分条件与必要条件

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | 充分不必要条件 | x>3 可推出 x>1，反推不成立。 |
| 2 | 充分不必要条件 | x=2 可推出 x^2=4，但 x=-2 也满足 q。 |
| 3 | 充分不必要条件 | 正方形一定是矩形，矩形不一定是正方形。 |
| 4 | 充要条件 | 偶数等价于能被 2 整除。 |
| 5 | 充分不必要条件 | a=b 可推出平方相等，平方相等不一定原数相等。 |
| 6 | 充分不必要条件 | 等边一定等腰，等腰不一定等边。 |
