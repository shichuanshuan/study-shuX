## 学习计划

### 第 91 天：第 13 周小测

小测要求：限时完成具体题目 10 道；统计集合、命题、条件判断各自错误数。

具体题目：

```text
1. A = {1,2,3}，B = {3,4}，求 A ∪ B
2. A = {x | -2 <= x < 3}，B = {x | x >= 1}，求 A ∩ B
3. U = {1,2,3,4,5}，A = {1,3,5}，求 A 的补集
4. 写出 {a,b,c} 的子集个数
5. 判断 {x | x^2 = 4} 与 {-2,2} 是否相等
6. 写出命题“存在实数 x，使 x^2 < 0”的否定
7. 判断命题“若 x > 1，则 x > 0”的真假
8. p: x > 2，q: x^2 > 4，判断 p 是 q 的什么条件
9. p: x = 0，q: xy = 0，判断 p 是 q 的什么条件
10. 解不等式 x^2 - x - 6 < 0，并用区间表示
```

巩固加练：

```text
1. 订正后按错题模块补做同类题 10-15 道
2. 正确率低于 80% 的模块，下周每天先回炉 10-15 分钟
3. 如果整次小测低于 70%，先回炉 2-3 天再进入下一周
```

错题加练：

```text
把 B/C/D 类错题各选 2 道，分别补 3 道同类题；D 类题必须回到对应知识点重新学一遍。
```

## 答案与解析

### 第 91 天：第 13 周小测

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | {1,2,3,4} | 并集取所有元素且不重复。 |
| 2 | [1,3) | 同时满足 -2<=x<3 与 x>=1。 |
| 3 | {2,4} | 在 U 中去掉 A 的元素。 |
| 4 | 8 | 3 个元素有 2^3 个子集。 |
| 5 | 相等 | x^2=4 的解为 -2,2。 |
| 6 | 对任意实数 x，都有 x^2>=0 | “存在”否定为“任意”，不等号取反。 |
| 7 | 真 | x>1 必有 x>0。 |
| 8 | 充分不必要条件 | x>2 可推出 x^2>4，反例 x<-2。 |
| 9 | 充分不必要条件 | x=0 可推出 xy=0，xy=0 不一定 x=0。 |
| 10 | (-2,3) | 分解为 (x-3)(x+2)<0，取两根之间。 |
