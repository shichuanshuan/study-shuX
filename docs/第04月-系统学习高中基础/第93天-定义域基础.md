## 学习计划

### 第 93 天：定义域基础

知识点：分母不为 0、根号内非负、零次幂底数不为 0。

练习任务：完成具体题目 6 道；每题写出限制条件。

订正重点：多个限制要取交集。

具体题目：

```text
1. 求 f(x) = 1/(x - 2) 的定义域
2. 求 f(x) = sqrt(x + 3) 的定义域
3. 求 f(x) = sqrt(2 - x) 的定义域
4. 求 f(x) = 1/sqrt(x - 1) 的定义域
5. 求 f(x) = (x - 3)^0 的定义域
6. 求 f(x) = sqrt(x + 1)/(x - 4) 的定义域
```

```text

3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```


## 答案与解析

### 第 93 天：定义域基础

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | x≠2 | 分母不能为 0。 |
| 2 | [-3,+∞) | 根号内 x+3>=0。 |
| 3 | (-∞,2] | 根号内 2-x>=0。 |
| 4 | (1,+∞) | 根号作分母，x-1>0。 |
| 5 | x≠3 | 0 次幂底数不能为 0。 |
| 6 | [-1,4)∪(4,+∞) | 根号要求 x>=-1，且 x≠4。 |
