## 学习计划

### 第 88 天：区间与集合综合

知识点：区间表示、数轴、集合运算和不等式。

练习任务：完成具体题目 6 道；用区间写最终答案。

订正重点：端点能否取到决定圆括号还是方括号。

具体题目：

```text
1. 用区间表示 x >= 2
2. 用区间表示 -1 < x <= 4
3. A = [-2,3]，B = (1,5)，求 A ∩ B
4. A = (-∞,2)，B = [-1,+∞)，求 A ∩ B
5. A = [-3,1]，B = [1,4]，求 A ∪ B
6. 解不等式 x^2 - 4 <= 0，并用区间表示解集
```

## 答案与解析

### 第 88 天：区间与集合综合

| 题号 | 答案 | 简要解析 / 易错点 |
|---|---|---|
| 1 | [2,+∞) | 大于等于用闭端点。 |
| 2 | (-1,4] | -1 不取，4 取。 |
| 3 | (1,3] | 1 不取，3 取。 |
| 4 | [-1,2) | 同时满足 x<2 且 x>=-1。 |
| 5 | [-3,4] | 两区间在 1 处相接，合成一个闭区间。 |
| 6 | [-2,2] | x^2-4=(x-2)(x+2)，小于等于 0 取两根之间。 |
