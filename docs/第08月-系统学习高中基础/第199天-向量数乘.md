## 学习计划

### 第 199 天：向量数乘

知识点：数乘、共线、方向、模的变化。

练习任务：完成具体题目 6 道；判断方向是否改变。

订正重点：数乘为负数时方向相反。

具体题目：

```text
1. 若 |a|=4，求 |3a|
2. 若 |a|=5，求 |-2a|
3. 判断 2a 与 a 是否同向
4. 判断 -3a 与 a 是否反向
5. 若 b=4a，判断 a 与 b 是否共线
6. 若 a、b 不共线，判断 a+b 与 a 是否一定共线
```
