## 学习计划

### 第 212 天：平行与垂直关系

知识点：线线平行、线面平行、线面垂直、面面垂直。

练习任务：完成具体题目 6 道；写出判定依据。

订正重点：线面垂直要垂直于平面内两条相交直线。

具体题目：

```text
1. 若直线 l 垂直平面 α，判断 l 是否垂直 α 内任意直线
2. 若直线 l 平行平面 α，判断 l 是否一定平行 α 内某条直线
3. 正方体中，棱 AA1 是否垂直底面 ABCD
4. 正方体中，平面 ABB1A1 是否垂直底面 ABCD
5. 若两个平面垂直，它们的交线与其中一个平面内任意直线是否垂直
6. 判断“垂直于同一平面的两条直线平行”是否正确
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```


## 答案与解析

### 第 212 天：平行与垂直关系

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 是 | 线面垂直则垂直平面内任意直线。 |
| 2 | 是 | 平面内存在与该直线平行的直线。 |
| 3 | 是 | 侧棱垂直底面。 |
| 4 | 是 | 相邻侧面与底面垂直。 |
| 5 | 不一定 | 只对特定垂直于交线的直线成立。 |
| 6 | 正确 | 垂直同一平面的两直线方向相同或相反。 |
