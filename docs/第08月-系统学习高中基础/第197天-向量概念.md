## 学习计划

### 第 197 天：向量概念

知识点：向量、模、零向量、相等向量、相反向量。

练习任务：完成具体题目 6 道；每题说明是大小问题还是方向问题。

订正重点：向量既有大小又有方向。

具体题目：

```text
1. 判断两个长度相等的线段表示的向量一定相等吗
2. 判断零向量有没有确定方向
3. 若 vector a 与 vector b 相等，说明它们的模和方向关系
4. 若 vector a 与 vector b 互为相反向量，写出 a+b
5. 已知 |a|=3，|-a| 等于多少
6. 判断平移后的同向等长有向线段是否表示同一向量
```

```text

3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

## 答案与解析

### 第 197 天：向量概念

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 不一定 | 向量相等还要求方向相同。 |
| 2 | 没有 | 零向量方向不确定。 |
| 3 | 模相等且方向相同 | 这是向量相等的条件。 |
| 4 | 0 | 相反向量相加为零向量。 |
| 5 | 3 | 相反向量模相等。 |
| 6 | 是 | 平移不改变向量。 |
