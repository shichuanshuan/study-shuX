## 学习计划

### 第 221 天：事件关系与独立入门

知识点：互斥、对立、独立事件基础。

练习任务：完成具体题目 6 道；每题判断事件关系。

订正重点：对立一定互斥，互斥不一定对立。

具体题目：

```text
1. 掷骰子，“出现奇数”和“出现偶数”是否对立
2. 掷骰子，“出现 1”和“出现 2”是否对立
3. 掷骰子，“出现小于 3”和“出现大于 4”是否互斥
4. 抛两枚硬币，第一枚正面与第二枚正面是否独立
5. 若 A、B 独立，P(A)=1/2，P(B)=1/3，求 P(AB)
6. 若 A、B 互斥，P(A)=0.2，P(B)=0.5，求 P(A∪B)
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 221 天：事件关系与独立入门

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 是 | 奇数与偶数互斥且并为全集。 |
| 2 | 不是 | 互斥但不是对立，还可能出现 3-6。 |
| 3 | 互斥 | 小于 3 与大于 4 不能同时发生。 |
| 4 | 独立 | 两枚硬币结果互不影响。 |
| 5 | 1/6 | 独立事件概率相乘。 |
| 6 | 0.7 | 互斥事件概率相加。 |
