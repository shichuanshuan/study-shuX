## 学习计划

### 第 207 天：平行与垂直

知识点：向量平行、垂直、坐标判定。

练习任务：完成具体题目 6 道；每题说明用平行还是垂直条件。

订正重点：平行看比例，垂直看数量积为 0。

具体题目：

```text
1. 判断 a=(2,3)，b=(4,6) 是否平行
2. 判断 a=(2,3)，b=(3,-2) 是否垂直
3. 若 a=(1,k)，b=(2,4) 平行，求 k
4. 若 a=(3,k)，b=(2,1) 垂直，求 k
5. A(0,0)，B(2,3)，C(4,6)，判断 A、B、C 是否共线
6. A(1,1)，B(3,2)，C(4,0)，判断 AB 与 AC 是否垂直
```

3. 如果本节具体题目有 C/D 类题，优先补同知识点题

## 答案与解析

### 第 207 天：平行与垂直

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 是 | b=2a。 |
| 2 | 是 | 数量积 6-6=0。 |
| 3 | k=2 | (1,k) 与 (2,4) 成比例。 |
| 4 | k=-6 | 6+k=0。 |
| 5 | 是 | AB 与 AC 成比例。 |
| 6 | 不垂直 | AB=(2,1)，AC=(3,-1)，数量积为 5。 |
