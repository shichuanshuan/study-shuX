## 学习计划

### 第 220 天：计数基础

知识点：分类加法、分步乘法、简单排列组合。

练习任务：完成具体题目 6 道；先判断分类还是分步。

订正重点：分类用加法，分步用乘法。

具体题目：

```text
1. 从 3 件上衣、2 条裤子中各选一件，有多少种搭配
2. 从 A 城到 B 城有 3 条路，B 到 C 有 4 条路，A 到 C 经 B 有多少种走法
3. 从 5 人中选 1 人，有多少种选法
4. 从 5 人中选 2 人组成小组，有多少种选法
5. 用数字 1、2、3 组成无重复数字的两位数，有多少个
6. 用数字 1、2、3 组成无重复数字的三位数，有多少个
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
