## 学习计划

### 第 198 天：向量加减法

知识点：三角形法则、平行四边形法则、向量减法。

练习任务：完成具体题目 6 道；每题画简图。

订正重点：向量减法可转化为加上相反向量。

具体题目：

```text
1. 已知 AB向量 + BC向量，结果是什么
2. 已知 AC向量 - AB向量，结果是什么
3. 平行四边形 ABCD 中，AB向量 + AD向量 等于什么
4. 若 a+b=0，判断 a 与 b 的关系
5. 化简 AB向量 + BC向量 + CD向量
6. 化简 AB向量 - AC向量
```

## 答案与解析

### 第 198 天：向量加减法

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | AC向量 | 首尾相接。 |
| 2 | BC向量 | AC-AB=BC。 |
| 3 | AC向量 | 平行四边形对角线法则。 |
| 4 | 互为相反向量 | a=-b。 |
| 5 | AD向量 | 连续首尾相接为 AD。 |
| 6 | CB向量 | AB-AC=AB+CA=CB。 |
