# 第 22 月冲刺 130+ 与冲 140 训练每日计划

配套完成标准与解析：[第22月冲刺130+与冲140训练完成标准与解析.md](/Users/shics/workspace/shuX/docs/第22月冲刺130+与冲140训练完成标准与解析.md)
> 主题：基础题满分化。目标是在已经能完成真题和模拟卷的基础上，把会做题做满分，把难题拿步骤分，把整卷节奏稳定下来。

---

## 一、本月目标

```text
1. 选择题前半部分、填空题前半部分接近满分
2. 解答题前 3 题追求满分或接近满分
3. 计算准确率和答题规范明显提升
4. 会做的题不丢分，低级错误控制在 1-2 处以内
```

本阶段使用说明：文中的“冲刺卷 1/2/3/4”指你手边的高质量模拟卷或最近一轮真题回炉卷；如果卷型不同，就按“选择填空、前 3 道解答题、导数、解析几何、压轴题”的功能位置替换。每天仍然使用 A/B/C/D 分类：A 类会做且做对；B 类会做但算错或不规范；C 类看答案能懂但独立做不出；D 类完全不会或暂时超出能力。

冲刺阶段的优先级：先清 B 类低级错误，再把高频 C 类题转成 B/A 类，最后才处理 D 类题。冲 140 不是每天刷最难题，而是让基础题接近满分、中档题稳定、压轴题有步骤分。

### 第 616 天：第 22 月基础满分化月测

知识点：选择前半、填空前半、前 3 解答题、计算准确率和答题规范。

练习任务：完成具体训练 10 项；按月度验收处理，统计分数、耗时、低级错误和冲刺状态。

订正重点：月测目标是确认会做的题基本不丢分，然后才进入压轴专题冲刺。

具体题目：

```text
1. 汇总本月选择前半正确率和平均耗时
2. 汇总本月填空前半正确率和平均耗时
3. 汇总本月前 3 道解答题得分率
4. 统计本月所有 B 类低级错误数量，目标下降到 1-2 处以内
5. 重做本月最典型 B 类题 8 道，要求一次正确
6. 重做本月最典型 C 类基础题 4 道，要求写出入口
7. 整理第 23 月导数压轴需要补的 3 个点
8. 整理第 23 月解析几何压轴需要补的 3 个点
9. 写出本月最有效的 5 条防错提醒
10. 写出下月压轴训练时不能牺牲的基础题底线
```

巩固加练：

```text
1. 从本月失分最高的 3 个模块各补同类题 8-10 道
2. 若普通卷低于 135，下一轮先修基础题和中档题，不急着冲难题
3. 整理稳定得分题型、波动题型、放弃题型和考前提醒四张清单
```

错题加练：

```text
整卷错题按 A/B/C/D 分类；B 类当天重算，C 类隔天重做，D 类只摘可拿步骤分入口并每周回看。
```
