# 第 1 月诊断与学习状态恢复每日计划

> 适用情况：毕业多年后重新学习高考数学。第 1 月不要追求快，目标是确认真实基础、恢复计算手感、建立稳定学习节奏。

---

## 一、本月目标

本月只做 4 件事：

```text
1. 找出当前最弱的 3 类问题
2. 恢复基础计算、方程、不等式、函数图像的手感
3. 建立错题本和学习记录
4. 稳定完成每周 6-8 小时学习
```

本月不追求：

```text
不追求做难题
不追求刷很多套卷
不追求马上进入高中复杂专题
不因为诊断分数低而否定自己
```

---

## 二、每天固定流程

每次学习建议 60-90 分钟。

```text
5 分钟：看今天目标
15-25 分钟：复习知识点
30-45 分钟：独立做题
15-20 分钟：订正、分类、记录错因
5 分钟：写下明天要补什么
```

错题统一分成 4 类：

```text
A 类：会做且做对
B 类：会做但算错
C 类：看答案能懂
D 类：完全不会
```

错题本每题只写 5 行：

```text
题目编号：
错因分类：B / C / D
我错在哪里：
正确方法：
重做日期：
```
