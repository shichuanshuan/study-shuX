# 第 16 月专题题型训练每日计划

> 主题：选择填空专项。目标是把学过的知识变成稳定可识别、可迁移、可得分的题型能力。

配套答案与解析：[答案与解析.md](./答案与解析.md)

配套错题本：[错题本.md](./错题本.md)

---

## 一、本月目标

```text
1. 提高选择填空基础题和中档题速度与正确率
2. 掌握排除、特殊值、数形结合、估算、极端法等小题策略
3. 训练函数、导数、数列、解析几何等压轴小题的识别入口
4. 形成限时小题组训练和错题回炉节奏
```

每天训练分三层：基础必做完成本小节“具体题目”；巩固加练继续补同类题；错题加练围绕当天错题对应知识点追加练习。专题训练阶段要特别重视“识别题型”和“第一步选择方法”。

### 第 448 天：选择填空专项月测

知识点：选择填空专项综合验收。

练习任务：完成具体题目 16 道；按月测处理，分模块限时，做完后统计本月薄弱专题。

订正重点：月测后统计选择填空正确率和耗时，把最慢的 3 类题列入下阶段真题训练。

具体题目：

```text
1. 求 A={1,2,3,4}，B={2,4,6} 的交集
2. 判断“x>2”是“x>1”的什么条件
3. 求 f(x)=sqrt(2x-1)/(x+1) 的定义域
4. 求 y=x^2-6x+11 的最小值
5. 判断 f(x)=x^3+x 的奇偶性
6. 求 y=sin x+cos x 的最大值
7. 解 sin x=1/2 在 [0,2pi] 内的解个数
8. 等差数列 a1=3，d=2，求 a20
9. 已知 Sn=n^2，求 a15
10. 求圆 x^2+y^2=25 被直线 y=3 截得弦长
11. 求椭圆 x^2/16+y^2/9=1 的离心率
12. 求向量 (1,2,2) 与 (2,0,1) 的数量积
13. 掷两枚骰子，求点数和为 7 的概率
14. 随机变量 X 取 1,2,3，概率 0.2,0.5,0.3，求 E(X)
15. 定义 a*b=a+b+ab，求 2*3
16. 写出本月选择填空最有效的 3 个提速策略
```

巩固加练：

```text
1. 订正后从本月错题最多的 3 个专题各补同类题 6-8 道
2. 把低于 80% 正确率的专题列入下月前两周回炉清单
3. 整理 5 条本月最常见失分原因，写到错题本首页
```

错题加练：

```text

```
