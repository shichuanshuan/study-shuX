## 学习计划

### 第 354 天：累加累乘

知识点：a(n+1)-a_n 型累加，a(n+1)/a_n 型累乘。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：累加累乘一定写出从 1 到 n-1 的连加或连乘范围。

具体题目：

```text
1. 已知 a1=2，a(n+1)-a_n=n，求 an
2. 已知 a1=1，a(n+1)-a_n=2n+1，求 an
3. 已知 a1=3，a(n+1)-a_n=1/n，写出 an 的累加表达式
4. 已知 a1=2，a(n+1)/a_n=(n+1)/n，求 an
5. 已知 a1=1，a(n+1)/a_n=2n/(n+1)，求 an
6. 已知 a(n+1)-a_n=3^n，a1=1，求 an
7. 已知 a(n+1)/a_n=(n+2)/(n+1)，a1=1，求 an
8. 判断递推 a(n+1)=a_n+2n 是否适合累加法
```
