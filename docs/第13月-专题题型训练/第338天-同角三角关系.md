## 学习计划

### 第 338 天：同角三角关系

知识点：sin^2 x+cos^2 x=1、tan x=sin x/cos x、象限符号。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：同角关系题必须结合象限，否则平方开方容易丢符号。

具体题目：

```text
1. 已知 sin x=3/5，且 x 在第二象限，求 cos x、tan x
2. 已知 cos x=-4/5，且 x 在第三象限，求 sin x、tan x
3. 已知 tan x=2，求 sin^2 x 和 cos^2 x 的关系
4. 化简 sin^2 x+cos^2 x+tan x cos x
5. 已知 sin x+cos x=1/2，求 sin x cos x
6. 已知 sin x cos x=1/4，求 (sin x+cos x)^2
7. 已知 tan x=3，求 (sin x+cos x)^2
8. 判断 sin x=2/3 时 cos x 是否唯一，并说明原因
```

```text
1. 按本节题型再补做同类题 10-15 道

3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```
