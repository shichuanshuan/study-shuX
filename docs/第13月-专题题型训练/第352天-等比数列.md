### 第 352 天：等比数列

知识点：等比数列定义、通项、前 n 项和、性质。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：等比题要注意 q=1 和正负公比，不能默认都是正数。

具体题目：

```text
1. 已知 a1=2，q=3，求 a6
2. 已知 a1=5，a4=40，求 q
3. 求等比数列 3,6,12,... 的前 8 项和
4. 已知 a2=6，a5=48，求 q 和 a1
5. 判断 81 是否为数列 1,3,9,... 的项
6. 已知等比数列 a3=12，a5=48，求 a4
7. 求等比数列 2,-4,8,-16,... 的通项公式
8. 已知 Sn=2^n-1，求 an 并判断是否等比
```
