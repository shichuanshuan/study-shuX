订正重点：综合变换先观察目标形式，不要盲目展开到底。

具体题目：

```text
1. 化简 sin(pi-x)+cos(pi/2+x)
2. 化简 cos^2 x - sin^2 x
3. 化简 2sin x cos x + cos 2x
4. 已知 sin x+cos x=1，求 sin 2x
5. 已知 tan x=1/2，求 sin 2x
6. 求 y=2sin x cos x + cos^2 x 的最大值
7. 证明 (sin x+cos x)^2=1+sin 2x
8. 把 sqrt(3)cos x+sin x 化为辅助角形式并求最大值
```
