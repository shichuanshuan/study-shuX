## 学习计划

### 第 341 天：辅助角公式

知识点：a sin x+b cos x 转化为 R sin(x+phi)。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：辅助角的核心是提出 R，并让系数对应 cos phi、sin phi。

具体题目：

```text
1. 把 sin x+cos x 化为辅助角形式
2. 把 sqrt(3)sin x+cos x 化为辅助角形式
3. 求 y=sin x+cos x 的最大值和最小值
4. 求 y=2sin x+2cos x 的最大值
5. 求 y=3sin x-4cos x 的最大值
6. 解方程 sin x+cos x=1 在 [0,2pi] 内的解
7. 求 y=sqrt(3)sin x-cos x 的周期和值域
8. 判断 a sin x+b cos x 的最大值与 a,b 的关系
```
