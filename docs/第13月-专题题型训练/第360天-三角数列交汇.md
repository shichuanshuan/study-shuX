## 学习计划

### 第 360 天：三角数列交汇

知识点：三角公式与数列规律结合。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：交汇题通常先看 n 引起的周期，再用数列思想求和。

具体题目：

```text
1. 已知 a_n=sin(n*pi/2)，写出前 8 项并判断周期
2. 已知 a_n=cos(n*pi)，求 a1 到 a6
3. 已知 a_n=sin n*pi/6，求 a6、a12
4. 求数列 a_n=2sin(n*pi/2) 的周期和值域
5. 已知 a_n=sin x + n cos x，判断关于 n 是否为等差数列
6. 若 a_n=sin x * 2^(n-1)，判断其关于 n 是否为等比数列
7. 求和 sin(pi/6)+sin(5pi/6)+sin(9pi/6)+sin(13pi/6)
8. 已知 a_n=cos(n*pi/3)，求前 12 项和
```

巩固加练：

```text
1. 按本节题型再补做同类题 10-15 道
2. 至少包含 4 道基础变式、4 道中档变式、2 道易错条件变式
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```
