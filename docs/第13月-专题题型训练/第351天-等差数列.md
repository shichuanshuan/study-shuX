## 学习计划

### 第 351 天：等差数列

知识点：等差数列定义、通项、前 n 项和、性质。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：等差题先找 a1 和 d，Sn 与 an 的关系要熟练。

具体题目：

```text
1. 已知 a1=3，d=2，求 a10
2. 已知 a1=5，a8=26，求 d
3. 已知等差数列 a3=7，a9=19，求 a1 和 d
4. 求等差数列 2,5,8,... 的前 20 项和
5. 已知 Sn=3n^2+2n，求 an
6. 已知 a4+a8=20，求 a6
7. 等差数列前 n 项和 Sn=n^2，求 a1 和 d
8. 判断 100 是否为数列 4,7,10,... 的项
```

巩固加练：

```text
1. 按本节题型再补做同类题 10-15 道

3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```
