## 学习计划

### 第 462 天：真题卷 A 周复盘与目标校准

知识点：周统计、目标分校准、下周补弱排序。

练习任务：完成具体训练 8 项；以二刷、回炉和周统计为主。

订正重点：周复盘要用数据决定下周练什么。

具体题目：

```text
1. 汇总 真题卷 A 本周已完成题目和未完成题目
2. 计算本周选择填空正确率和平均耗时
3. 计算前 3 道解答题得分率，目标接近满分
4. 列出 B 类题前 5 个高频原因
5. 列出 C 类题前 3 个高频知识点
6. 判断本周整卷估分是否达到 估分 115-120
7. 为下周写出 2 个最优先补弱专题
8. 重做本周最典型错题 2 道，确认是否降级为 A/B 类
```

巩固加练：

```text
1. 从本周错题最多的 2 个模块各补同类题 5-8 道
2. 把仍然不稳的题标成 C/D 类，放入下周第 1 天预热
3. 重做时遮住答案，只保留题干和自己的错误原因
```

错题加练：

```text
二刷仍错的题直接升级为 C/D 类，写明卡点：审题、公式、计算、方法、时间。
```
