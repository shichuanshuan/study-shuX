# 第 2-3 月补初中核心基础答案与解析

## 使用方法

1. 先独立完成每日计划中的题目，再对照本文件订正；不要边看答案边做。
2. 每题按“答案”和“简要解析 / 易错点”检查，错题立即标注 A/B/C/D。
3. B 类题重点复查计算和符号，C/D 类题要写入错题本并安排重做日期。
4. 开放说明题没有唯一答案，按“参考要点”检查是否写到关键动作和证据。

## A/B/C/D 分类说明

| 分类 | 含义 | 处理方式 |
|---|---|---|
| A 类 | 会做且做对 | 简单标记通过，不必反复抄写。 |
| B 类 | 会做但算错 | 找出符号、通分、去括号、代入等具体失误，隔天重做。 |
| C 类 | 看答案能懂 | 补写关键步骤，遮住答案后重做同类题。 |
| D 类 | 完全不会 | 回到对应知识点和例题，先重学再做题。 |
