## 学习计划

### 第 172 天：等差数列前 n 项和

知识点：`S_n = n(a_1+a_n)/2`，`S_n = n a_1 + n(n-1)d/2`。

练习任务：完成具体题目 6 道；先判断已知条件适合哪个公式。

订正重点：`S_n` 是和，`a_n` 是项。

具体题目：

```text
1. 等差数列 a_1=1，a_10=19，求 S_10
2. 等差数列 a_1=3，d=2，求 S_8
3. 求 2+4+6+...+100
4. 求 1+3+5+...+99
5. 等差数列 a_1=5，d=-1，求 S_6
6. 已知等差数列 a_1=2，S_5=40，求 d
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```
