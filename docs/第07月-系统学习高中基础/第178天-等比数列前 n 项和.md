## 学习计划

### 第 178 天：等比数列前 n 项和

知识点：`S_n = a_1(1-q^n)/(1-q)`，`q != 1`。

练习任务：完成具体题目 6 道；先判断 q 是否等于 1。

订正重点：公式分母是 `1-q`，不要和 `q-1` 混用。

具体题目：

```text
1. 等比数列 a_1=1，q=2，求 S_5
2. 等比数列 a_1=3，q=2，求 S_4
3. 等比数列 a_1=16，q=1/2，求 S_4
4. 求 1+2+4+8+16
5. 求 3+6+12+24
6. 等比数列 a_1=5，q=1，求 S_10
```
