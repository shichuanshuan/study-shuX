知识点：等差、等比、通项形式辨析。

订正重点：看差固定还是比固定。

具体题目：

```text
1. 判断 1,4,7,10 是等差还是等比
2. 判断 2,6,18,54 是等差还是等比
3. 数列 a_n=3n+2 是等差还是等比
4. 数列 a_n=2^n 是等差还是等比
5. 数列 1,1,1,1 同时是等差和等比吗
6. 写出一个既不是等差也不是等比的数列
```

## 答案与解析

### 第 181 天：等差与等比辨析

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 等差 | 公差为 3。 |
| 2 | 等比 | 公比为 3。 |
| 3 | 等差 | a_{n+1}-a_n=3。 |
| 4 | 等比 | a_{n+1}/a_n=2。 |
| 5 | 是 | 公差为 0，公比为 1。 |
| 6 | 参考要点：如 1,2,4,7 | 相邻差和相邻比都不恒定。 |
