## 学习计划

### 第 169 天：数列概念

知识点：数列、项、通项、递推。

练习任务：完成具体题目 6 道；区分第 n 项和前 n 项和。

订正重点：`a_n` 是第 n 项，不是前 n 项和。

具体题目：

```text
1. 数列 2,4,6,8,... 的第 5 项是多少
2. 数列 a_n = 3n - 1，求 a_1、a_5
3. 数列 a_n = n^2，求 a_4
4. 已知 a_1=2，a_{n+1}=a_n+3，求 a_2、a_3
5. 写出数列 1,4,9,16,... 的一个通项公式
6. 判断 1,3,6,10,... 是否等差数列
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 169 天：数列概念

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 5 | 按顺序第 5 项为 10。 |
| 2 | a_1=2，a_5=14 | 代入 a_n=3n-1。 |
| 3 | 16 | 代入 n=4 得 4^2。 |
| 4 | a_2=5，a_3=8 | 每次比前一项多 3。 |
| 5 | a_n=n^2 | 1,4,9,16 是平方数列。 |
| 6 | 不是 | 相邻差为 2,3,4，不恒定。 |
