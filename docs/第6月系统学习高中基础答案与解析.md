# 第6月系统学习高中基础答案与解析

## 使用方法

先独立完成每日计划中的题目，再对照本文件订正。订正时不要只抄答案，要把错题归入 A/B/C/D，并在原题旁补一句“错因”和“一步改法”。

A/B/C/D 分类说明：A 类为熟练正确；B 类为会做但计算、符号或表述有小错；C 类为思路不稳、需要看提示才能完成；D 类为概念不会或无法独立起步。B 类当天复算 1 遍，C/D 类当天补同类题 3-5 道。
