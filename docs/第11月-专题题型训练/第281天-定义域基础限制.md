## 答案与解析

### 第 281 天：定义域基础限制

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | x!=2 | 分母不为 0。 |
| 2 | [ -3,+∞ ) | 被开方数 x+3>=0。 |
| 3 | (-∞,2] 且 x!=-1 | 根式要求 x<=2，分母要求 x!=-1。 |
| 4 | (1,+∞) | 对数真数 x-1>0。 |
| 5 | (4,+∞) | 分母中的根式要 x-4>0。 |
| 6 | (-1/2,+∞) 且 x!=2 | 真数 2x+1>0，分母 x-2!=0。 |
| 7 | (-∞,-2]∪[2,+∞) | x^2-4>=0。 |
| 8 | (-∞,3] 且 x!=-2 | 根式 x<=3，分母 x!=-2。 |
