具体题目：

```text
1. 比较 2^1.5 与 2^2 的大小
2. 比较 (1/2)^1 与 (1/2)^3 的大小
3. 求 y=2^x 的定义域和值域
4. 求 y=log_2 x 的定义域和值域
5. 判断 y=log_(1/2) x 的单调性
6. 解不等式 2^x>8
7. 解不等式 log_2 x<3
8. 判断 y=x^3 与 y=sqrt(x) 的图像在第一象限的大致变化差异
```
