# 第9月系统学习高中基础错题本

> 配套计划：[每日计划.md](./每日计划.md)
> 配套答案与解析：[答案与解析.md](./答案与解析.md)

## 使用方法

```text
1. 每天做完题后，先对答案，再给每题标 A/B/C/D
2. A 类只统计数量，不抄题
3. B/C/D 类写入当天错题表
4. 每周复盘时，只看 B 类是否减少、C 类是否能转成 B/A、D 类是否回到知识点
```

分类标准：A 类会做且做对；B 类会做但算错或不规范；C 类看答案能懂但独立做不出；D 类完全不会或看答案也不懂。

本阶段有固定题目；“题号/训练项”直接写当天题号，例如“第 5 题”。
