## 学习计划

### 第 244 天：直线与圆锥曲线入门

知识点：联立、交点、判别式。

练习任务：完成具体题目 5 道；只做基础消元。

订正重点：联立后用判别式判断交点个数。

具体题目：

```text
1. 联立 y=0 与 y^2=4x，求交点
2. 联立 x=1 与 y^2=4x，求交点
3. 联立 y=x 与 y^2=4x，写出关于 x 的方程
4. 联立 y=x 与 x^2/4+y^2=1，写出关于 x 的方程
5. 判断直线 y=3 与抛物线 y^2=4x 是否有交点
```
