## 学习计划

### 第 233 天：椭圆几何性质

知识点：顶点、焦点、离心率、范围。

练习任务：完成具体题目 6 道；每题写出顶点和焦点。

订正重点：离心率 `e=c/a`，且 `0<e<1`。

具体题目：

```text
1. 求 x^2/16 + y^2/9 = 1 的顶点坐标
2. 求 x^2/16 + y^2/9 = 1 的焦点坐标
3. 求 x^2/16 + y^2/9 = 1 的离心率
4. 求 y^2/25 + x^2/9 = 1 的焦点坐标
5. 写出 x^2/9 + y^2/4 = 1 中 x、y 的取值范围
6. 判断椭圆离心率越大图像越圆还是越扁
```
