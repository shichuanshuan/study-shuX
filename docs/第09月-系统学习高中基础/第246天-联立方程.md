## 学习计划

### 第 246 天：联立方程

知识点：直线代入圆锥曲线、消元、一元二次方程。

练习任务：完成具体题目 6 道；写出消元后的方程。

订正重点：联立是解析几何综合题的第一步。

具体题目：

```text
1. 联立 y=x 与 x^2+y^2=2，写出关于 x 的方程
2. 联立 y=x 与 x^2/4+y^2=1，写出关于 x 的方程
3. 联立 y=2x 与 y^2=4x，写出关于 x 的方程
4. 联立 y=x+1 与 x^2+y^2=5，写出关于 x 的方程
5. 联立 y=0 与 x^2/9+y^2/4=1，求交点
6. 联立 x=1 与 y^2=4x，求交点
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
