## 学习计划

### 第 237 天：椭圆大题第一问训练

知识点：求标准方程、求焦点、求离心率。

练习任务：完成具体题目 6 道；每题按“设方程-代条件-求参数”写。

订正重点：大题第一问先求出标准方程。

具体题目：

```text
1. 焦点在 x 轴，过 (3,0)、(0,2)，求椭圆方程
2. 焦点为 (±4,0)，长轴长 10，求椭圆方程
3. 椭圆 x^2/25+y^2/9=1，求离心率
4. 椭圆 y^2/16+x^2/7=1，求焦点坐标
5. 已知 a=5，e=4/5，焦点在 x 轴，求方程
6. 椭圆上一点到两焦点距离和为 12，求长轴长
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
