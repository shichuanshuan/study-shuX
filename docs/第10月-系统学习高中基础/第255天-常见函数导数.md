## 学习计划

### 第 255 天：常见函数导数

知识点：常数、幂函数、一次函数、二次函数导数。

练习任务：完成具体题目 8 道；每题写出公式。

订正重点：`(x^n)' = nx^(n-1)`。

具体题目：

```text
1. 求 f(x)=5 的导数
2. 求 f(x)=x 的导数
3. 求 f(x)=x^2 的导数
4. 求 f(x)=x^3 的导数
5. 求 f(x)=2x^2 的导数
6. 求 f(x)=3x^3-2x 的导数
7. 求 f(x)=1/x 的导数
8. 求 f(x)=sqrt(x) 的导数
```
