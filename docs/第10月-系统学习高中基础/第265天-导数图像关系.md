## 学习计划

### 第 265 天：导数图像关系

知识点：函数图像、导函数图像、单调性和极值。

练习任务：完成具体题目 6 道；从导数符号读函数变化。

订正重点：看 `f'(x)` 图像在 x 轴上方还是下方。

具体题目：

```text
1. 若 f'(x)>0 在区间 (0,2) 上成立，f 在该区间单调性如何
2. 若 f'(x)<0 在区间 (-1,1) 上成立，f 在该区间单调性如何
3. 若 f'(x) 从正变负，f 在该点取得什么极值
4. 若 f'(x) 从负变正，f 在该点取得什么极值
5. 若 f'(x)=0 但左右都为正，是否一定有极值
6. 若导函数图像与 x 轴交于 -1、2，可能的临界点有哪些
```

```text
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

## 答案与解析

### 第 265 天：导数图像关系

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 递增 | 导数为正。 |
| 2 | 递减 | 导数为负。 |
| 3 | 极大值 | 函数先增后减。 |
| 4 | 极小值 | 函数先减后增。 |
| 5 | 不一定 | 导数左右符号不变则无极值。 |
| 6 | -1 和 2 | 导函数为 0 的点是可能临界点。 |
