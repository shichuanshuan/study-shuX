## 学习计划

### 第 260 天：导数符号与单调性

知识点：导数正负、递增递减、单调区间。

练习任务：完成具体题目 6 道；每题解 `f'(x)>0` 和 `f'(x)<0`。

订正重点：导数大于 0 对应递增，小于 0 对应递减。

具体题目：

```text
1. f(x)=x^2，求递增区间和递减区间
2. f(x)=x^2-4x，求单调区间
3. f(x)=-x^2+2x，求单调区间
4. f(x)=x^3，判断在 R 上的单调性
5. f(x)=x^3-3x，求 f'(x)
6. 对 f'(x)=2x-4，写出函数递增区间
```

巩固加练：

```text
1. 按本节知识点再补做同类基础题 8-12 道
2. 至少包含 3 道换数字题、3 道换条件题、2 道换问法题
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 3-5 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
