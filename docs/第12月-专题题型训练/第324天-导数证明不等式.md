订正重点：证明不等式时先把一边移到另一边，构造函数找最值。

具体题目：

```text
1. 证明 x>0 时 ln x <= x-1
2. 证明 x>=0 时 e^x >= 1+x
3. 证明 x>0 时 x+1/x >= 2
4. 证明 x>=0 时 x^2+1 >= 2x
5. 证明 x>1 时 ln x > (x-1)/x
6. 设 F(x)=x-ln x，求其最小值并推出不等式
7. 设 F(x)=e^x-x-1，证明 F(x)>=0
8. 用导数证明 x>0 时 x-ln x-1>=0
```
