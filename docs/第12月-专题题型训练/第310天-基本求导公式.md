## 学习计划

### 第 310 天：基本求导公式

知识点：常数、幂函数、指数、对数、三角函数基本导数。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：求导公式要先识别函数类型，幂函数的指数可以是分数和负数。

具体题目：

```text
1. 求 f(x)=7 的导数
2. 求 f(x)=x^5 的导数
3. 求 f(x)=3x^4-2x^2+x 的导数
4. 求 f(x)=1/x 的导数
5. 求 f(x)=sqrt(x) 的导数
6. 求 f(x)=e^x+ln x 的导数
7. 求 f(x)=sin x+cos x 的导数
8. 求 f(x)=2^x 的导数可写成什么形式
```

巩固加练：

```text
1. 按本节题型再补做同类题 10-15 道
2. 至少包含 4 道基础变式、4 道中档变式、2 道易错条件变式
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 4-6 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 310 天：基本求导公式

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 0 | 常数导数为 0。 |
| 2 | 5x^4 | 幂函数求导。 |
| 3 | 12x^3-4x+1 | 逐项求导。 |
| 4 | -1/x^2 | 写成 x^(-1)。 |
| 5 | 1/(2sqrt(x)) | 写成 x^(1/2)。 |
| 6 | e^x+1/x | 逐项求导。 |
| 7 | cos x-sin x | 三角函数求导。 |
