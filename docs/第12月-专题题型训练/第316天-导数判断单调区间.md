## 学习计划

### 第 316 天：导数判断单调区间

知识点：求导、解 f'(x)>0 或 f'(x)<0、写单调区间。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：单调区间不能漏定义域，导数为 0 的点要作为分界点。

具体题目：

```text
1. 求 f(x)=x^2-4x+1 的单调区间
2. 求 f(x)=x^3-3x 的单调区间
3. 求 f(x)=x^3-6x^2+9x 的单调区间
4. 求 f(x)=ln x - x 的单调区间
5. 求 f(x)=x+1/x(x>0) 的单调区间
6. 求 f(x)=e^x-x 的单调区间
7. 求 f(x)=x^2-2ax+1 的单调区间
8. 已知 f'(x)=(x-1)(x+2)，写出 f(x) 的单调区间
```

巩固加练：

```text
1. 按本节题型再补做同类题 10-15 道
2. 至少包含 4 道基础变式、4 道中档变式、2 道易错条件变式
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 4-6 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 316 天：导数判断单调区间

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 递减 (-∞,2)，递增 (2,+∞) | f'=2x-4。 |
| 2 | 递增 (-∞,-1),(1,+∞)，递减 (-1,1) | f'=3(x^2-1)。 |
| 3 | 递增 (-∞,1),(3,+∞)，递减 (1,3) | f'=3(x-1)(x-3)。 |

| 8 | 递增 (-∞,-2),(1,+∞)，递减 (-2,1) | 看导数符号。 |
