# 第 12 月专题题型训练答案与解析

> 配套文件：[每日计划.md](./每日计划.md)

配套错题本：[错题本.md](./错题本.md)

## 使用方法

```text
1. 先独立完成当天题目，再用本文件订正
2. 每题订正后标 A/B/C/D，并把 B/C/D 题写入错题本
3. B 类当天重做，C 类补同类基础题，D 类先回到知识点和例题
4. 证明、思路、新定义、复盘类题目以“参考要点/完成标准”为准
```

分类标准：A 类会做且做对；B 类会做但算错或表达不规范；C 类看答案能懂但独立做不出；D 类完全不会或看答案也不懂。
