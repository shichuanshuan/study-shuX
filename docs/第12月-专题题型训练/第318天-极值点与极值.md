## 学习计划

### 第 318 天：极值点与极值

知识点：导数变号、极大值、极小值、驻点不是必然极值点。

练习任务：完成具体题目 8 道；全部围绕当天知识点，先独立完成再订正。

订正重点：极值看导数是否变号，不是只看 f'(x)=0。

具体题目：

```text
1. 求 f(x)=x^3-3x 的极值
2. 求 f(x)=x^3-6x^2+9x 的极值
3. 求 f(x)=x^4-2x^2 的极值
4. 求 f(x)=x+1/x(x>0) 的极值
5. 已知 f'(x)=(x-1)(x-3)，判断 x=1、x=3 处的极值类型
6. 已知 f'(x)=(x-2)^2，判断 x=2 是否一定为极值点
7. 求 f(x)=ln x - x 的极值
8. 求 f(x)=x^3+ax^2+1 在 x=0 处有极值时 a 的条件
```

巩固加练：

```text
1. 按本节题型再补做同类题 10-15 道
2. 至少包含 4 道基础变式、4 道中档变式、2 道易错条件变式
3. 如果本节具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 4-6 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```

## 答案与解析

### 第 318 天：极值点与极值

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | 极大值 2，x=-1；极小值 -2，x=1 | 导数 3(x^2-1)。 |
| 2 | 极大值 4，x=1；极小值 0，x=3 | 导数变号。 |
| 3 | 极大值 0，x=0；极小值 -1，x=±1 | 导数 4x(x^2-1)。 |
| 4 | 极小值 2，x=1 | 导数由负变正。 |
| 5 | x=1 极大，x=3 极小 | 导数 +,-,+ 变号。 |
| 6 | 不一定 | 导数不变号时不是极值。 |
| 7 | 极大值 -1，x=1 | 导数由正变负。 |
| 8 | a!=0 | x=0 为驻点，a!=0 时导数变号。 |
