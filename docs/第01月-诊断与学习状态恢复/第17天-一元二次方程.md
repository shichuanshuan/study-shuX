知识点：

```text

```

题目：

```text
1. x^2 = 25
2. x^2 - 16 = 0
3. x^2 - 7x + 10 = 0
4. x^2 + 3x + 2 = 0
5. x^2 - 2x - 8 = 0
6. 2x^2 - 8x = 0
7. x^2 + 4x + 1 = 0
8. 判断 x^2 - 6x + 9 = 0 的根的情况
9. 判断 x^2 + x + 1 = 0 的根的情况
10. 方程 x^2 - 5x + 6 = 0 的两根和与积分别是多少
```

巩固加练：

```text
1. 按当天知识点再补做同类基础题 5-10 道
2. 至少包含 2 道换数字题、2 道换条件题、1 道换问法题
3. 如果当天具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 2-4 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
