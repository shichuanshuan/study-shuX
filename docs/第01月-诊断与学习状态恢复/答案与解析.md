# 第 1 月诊断与学习状态恢复答案与解析

> 配套文件：[每日计划.md](./每日计划.md)

配套错题本：[错题本.md](./错题本.md)

## 使用方法

```text
1. 先独立完成当天题目，不要边做边看答案
2. 对答案后给每题标 A/B/C/D
3. B 类：会做但算错，当天重做 1 遍，隔天再重做 1 遍
4. C 类：看答案能懂，回到对应知识点补 2-3 道同类基础题
5. D 类：看答案也不懂，先重新学知识点，再做最基础例题
```

分类标准：A 类会做且做对；B 类会做但算错或不规范；C 类看答案能懂但独立做不出；D 类完全不会或看答案也不懂。
