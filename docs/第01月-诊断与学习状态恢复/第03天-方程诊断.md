## 学习计划

### 第 3 天：方程诊断

知识点：

```text
一元一次方程
二元一次方程组
一元二次方程
判别式
根与系数关系
```

题目：

```text
1. 2x + 5 = 17
2. 3(x - 2) = 12
3. 5x - 2 = 2x + 10
4. (x - 1)/2 = 3
5. 2x/3 + 1 = 5
6. 解方程组：x + y = 7，x - y = 1
7. 解方程组：2x + y = 8，x + y = 5
8. x^2 - 9 = 0
9. x^2 - 5x + 6 = 0
10. x^2 + 4x + 4 = 0
11. 2x^2 - 8 = 0
12. x^2 + x - 6 = 0
13. 判断 x^2 + 2x + 5 = 0 有无实根
14. 方程 x^2 - 3x + 2 = 0 的两根和是多少
15. 方程 2x^2 - 5x + 3 = 0 的两根积是多少
```


订正重点：

```text
移项是否变号
分母是否正确消去
一元二次方程能否优先因式分解
判别式 Δ = b^2 - 4ac 是否会用
```

巩固加练：

```text
1. 诊断日不大量加题；先把当天错题按知识点归类
2. 每个 C/D 类知识点补做同类基础题 2-3 道
3. B 类计算错题当天重做 1 遍，隔天再重做 1 遍
```

错题加练：

```text
错哪个知识点，只补对应知识点，不跨模块刷题；连续错 2 道时，先回看知识点和例题。
```
