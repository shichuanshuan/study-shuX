# 第 6 天：诊断复盘

> 由原总文件拆分：每日计划、答案与解析、错题本。

## 学习计划

### 第 6 天：诊断复盘

任务：

```text
1. 把第 1-5 天所有错题按 B/C/D 分类
2. 统计错误最多的 3 个知识点
3. 每类挑 2 道错题重做
4. 写出第 2 周优先补什么
```

巩固加练：

```text
1. 从本周或本月错题最多的 2 个知识点中各补做同类题 3-5 道
2. 只补基础同类题，不做新难题
3. 把仍然不会的题加入下一周开头的回炉清单
```

错题加练：

```text
复盘日以重做错题为主；D 类题必须写出对应知识点，再补 2-3 道最基础同类题。
```

复盘表：

```text

错误最多的知识点 3：
B 类题数量：
C 类题数量：
D 类题数量：
第 2 周最先补：
```

## 答案与解析

### 第 6 天：诊断复盘

本日没有固定计算答案，完成标准如下：

```text
1. 能列出第 1-5 天每一天的 B/C/D 类题号
2. 能找出最弱的 3 个知识点
3. 每个最弱知识点至少补 2-3 道同类基础题
4. B 类错题已经当天重做，且安排隔天重做
```
