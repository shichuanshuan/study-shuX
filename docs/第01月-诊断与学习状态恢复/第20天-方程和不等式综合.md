## 学习计划

### 第 20 天：方程和不等式综合

题目：

```text
1. 2(x + 3) = 18
2. x/4 + 2 = 5
3. x^2 - 4x + 3 = 0
4. 2x^2 + x - 3 = 0
5. 解方程组：x + y = 6，2x - y = 3
6. 解不等式：4 - 2x >= 10
7. 解不等式：3x + 2 < x + 8
8. 解不等式组：x >= 2，x <= 6
9. 若 x^2 - 3x + 2 = 0，求两根和
10. 若方程 x^2 + kx + 4 = 0 的两根和为 -5，求 k
```

巩固加练：

```text
1. 按当天知识点再补做同类基础题 5-10 道
2. 至少包含 2 道换数字题、2 道换条件题、1 道换问法题
3. 如果当天具体题目有 C/D 类题，优先补同知识点题
```

错题加练：

```text
错哪个知识点，当天追加同类题 2-4 道；如果连续错 2 道，第二天先回炉该知识点再进入新内容。
```
