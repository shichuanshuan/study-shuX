## 学习计划

### 第 4 天：不等式和函数诊断

知识点：

```text
不等式性质
一元一次不等式
区间表示
一次函数
二次函数基础图像
```

题目：

```text
1. 解不等式：x + 3 > 7
2. 解不等式：2x - 1 <= 5
3. 解不等式：-3x > 6
4. 解不等式：5 - x >= 2
5. 解不等式组：x > 1，x < 5
6. 函数 y = 2x + 1，当 x = 3 时 y 等于多少
7. 一次函数 y = -x + 4 与 y 轴交点是多少
8. 一次函数 y = 3x - 6 与 x 轴交点是多少
9. 二次函数 y = x^2 - 4x + 3 的对称轴是多少
10. 二次函数 y = x^2 - 4x + 3 的顶点横坐标是多少
11. 二次函数 y = -x^2 + 2x + 1 开口向上还是向下
12. 函数 y = 1/x 的自变量 x 不能取什么值
13. 函数 y = sqrt(x - 2) 的自变量 x 应满足什么条件
14. 若 f(x) = x^2 + 1，求 f(3)
15. 若 f(x) = 2x - 5，求 f(a + 1)
```


订正重点：

```text
不等式乘除负数是否变号
一次函数截距是否看清
二次函数对称轴 x = -b/(2a) 是否会用
定义域限制是否记得
```

巩固加练：

```text
1. 诊断日不大量加题；先把当天错题按知识点归类
2. 每个 C/D 类知识点补做同类基础题 2-3 道
3. B 类计算错题当天重做 1 遍，隔天再重做 1 遍
```

错题加练：

```text
错哪个知识点，只补对应知识点，不跨模块刷题；连续错 2 道时，先回看知识点和例题。
```

## 答案与解析

### 第 4 天：不等式和函数诊断

| 题号 | 答案 | 简要解析 / 易错点 |
| --- | --- | --- |
| 1 | x>4 | 两边减 3。 |
| 2 | x<=3 | 2x<=6。 |
| 3 | x<-2 | 除以负数 -3，不等号方向改变。 |
| 4 | x<=3 | -x>=-3，除以 -1 变号。 |
| 5 | 1<x<5 | 两个条件取交集。 |
| 6 | 7 | y=2×3+1。 |
| 7 | (0,4) | 与 y 轴交点令 x=0。 |
| 8 | (2,0) | 与 x 轴交点令 y=0，3x-6=0。 |
| 9 | x=2 | 对称轴 x=-b/(2a)=4/2。 |
| 10 | 2 | 顶点横坐标就是对称轴 x=2。 |
| 11 | 向下 | 二次项系数 -1<0。 |
| 12 | x 不能取 0 | 分母不能为 0。 |
| 13 | x>=2 | 根号内 x-2>=0。 |
| 14 | 10 | f(3)=3^2+1。 |
| 15 | 2a-3 | f(a+1)=2(a+1)-5。 |
