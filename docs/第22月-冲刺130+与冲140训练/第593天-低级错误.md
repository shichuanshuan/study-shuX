## 学习计划

### 第 593 天：低级错误

知识点：低级错误。

练习任务：完成具体训练 8 项；全部围绕当天薄弱题型补同类题。

订正重点：低级错误清零的目标是把会做题做满分，不是增加新难度。

具体题目：

```text
1. 统计最近 4 套卷所有 B 类题题号和错误原因
2. 把 B 类题分成审题、计算、公式、抄写、时间五类
3. 重做审题错题 3 道，要求圈出关键词
4. 重做计算错题 3 道，要求每步竖排验算
5. 重做公式错题 3 道，要求先默写公式再做题
6. 重做抄写错题 3 道，要求对照题干检查条件
7. 写出每类低级错误的考场防错动作
8. 做一组基础题 12 道，目标 0 个低级错误
```

巩固加练：

```text
1. 按当天题型再补做同类题 10-15 道
2. 至少包含 5 道基础变式、5 道中档变式、2 道限时题
3. 补题后用一句话写出识别信号，再用一句话写出最容易错的地方
```

错题加练：

```text
补弱题仍错的知识点，当天追加同类题 4-6 道；如果仍连续错，暂停新卷一天回炉该专题。
```
