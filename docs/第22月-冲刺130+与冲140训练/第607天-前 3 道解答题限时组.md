## 学习计划

### 第 607 天：前 3 道解答题限时组

知识点：前排解答题 45-50 分钟完成、过程分完整。

练习任务：完成具体训练 8 项；以错题二刷、回炉和清单整理为主。

订正重点：前 3 道解答题要形成固定节奏，不能拖慢整卷。

具体题目：

```text
1. 限时 50 分钟完成前 3 道解答题综合组
2. 每道题先写得分点，再正式作答
3. 做完后按评分标准估分
4. 重写所有扣分步骤，直到表达完整
5. 从错题中选 2 道遮答案重做
6. 补做同类前排解答题 3 道
7. 整理自己最容易漏写的 5 个过程点
8. 记录总耗时，判断是否影响后半卷
```

巩固加练：

```text
1. 从最近两周错题最多的 2 个模块各补同类题 5-8 道
2. 重做时遮住答案，只保留题干和自己上次的错误原因
3. 二刷仍错的题放进考前高频错题清单，每 3 天回看一次
```

错题加练：

```text
二刷仍错的题升级为 C/D 类，写清卡点：审题、公式、计算、方法、时间或心态。
```
